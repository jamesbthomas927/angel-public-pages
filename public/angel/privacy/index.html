Privacy Notice

Friend beta · Updated August 15, 2026

Your personal context is part of the product, not advertising inventory.

AngelAI is designed to use conversation history, memories, profile context, and user-provided Library sources to provide continuity. This notice describes the current friend-beta data path reflected in the deployed engineering design.

Information Angel may process

  • Email and account identity for sign-in and account security.
  • Conversation messages for responses and continuity.
  • Memories derived from conversation for relevant personal context.
  • Onboarding reflections stored on the device, plus an onboarding-completion flag in Supabase.
  • Dragonfly safety/orchestration signals and bounded numeric response-quality measurements.
  • Optional message feedback and short beta reports.
  • Private Library sources and passages a user chooses to add.
  • Message content sent server-side to the model provider to generate a response.

Where information is stored and processed

Account, conversation, memory, feedback, Library, and related application records use Supabase. Model-generation requests are sent server-side to the configured OpenAI API; provider credentials are not placed in the mobile app. Angel requests provider-side storage to be disabled where supported, but provider retention is governed by the provider's applicable policies and settings.

Private beta reports

Angel's beta-report path is intentionally bounded. Reports contain the category, short user-entered details, screen, platform, app version when available, status, and timestamps. The founder review view is designed not to expose reporter identity and does not automatically attach chats, Library text, screenshots, credentials, or account identity.

Access and isolation

Personal application data is intended to be user-isolated. Sensitive application tables are accessed through Angel's authenticated backend rather than directly from the mobile client. Row-level security remains enabled as defense in depth.

Deletion and control

Angel includes account-deletion and source-deletion paths in the current product design. Profile-owned records are designed to cascade with account deletion. Device-local onboarding reflections can be removed with local app data. Users should also be able to correct or remove personal memories through Angel's controls as those surfaces are released.

Beta status

AngelAI is still in friend beta. Data practices may change as features are added or removed. This page will be updated when the deployed data path materially changes.
